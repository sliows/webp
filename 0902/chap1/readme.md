
***1.	웹의 구성
  a.	웹은 웹 서버와 웹 클라이언트로 구성된다.
    i.	웹 서버란? - 서버에 접속한 클라이언트에 웹 서비스를제공하기 위한 소프트웨어이다.
   ii.	웹 클라이언트란? - 서버에 요청하여 서버가 제공하는 서비스에 접근하는 하드 웨어나, 소프트 웨어에 의존하는 컴퓨터 프로그         램이다.
  iii.	정리 - 즉 서버는 클라이언트가 요청한 정보나 파일 등을 보내주는	 역할을 하고 클라이언트는 필요한 정보나 파일 등을 서버로         부터 요청하여 제공 받는다.
2.	웹 브라우저
  a.	웹 브라우저란? 
    i.	HTML 문서와 그림 등 웹 을 기반으로 한 인터넷의 콘텐츠에 접근하기 위한 응용 프로그램의 총칭이다.
   ii.	웹 브라우저에는 크롬, 파이어 폭스, 마이크로 소프트 엣지, 사파리 등이 있는데 이 중 크롬이 제일 사용량이 높다
      1.	크롬의 사용이 많은 이유는 사용자가 이용하기 편한 확장 프로그램이 많기 때문이다.
3.	웹 사이트 구축
  a.	 웹 사이트 구축하기 위해 웹 서버 소프트 웨어, 데이터베이스, 웹 서버 응용프로그램 개발 및 설치가 필요하다.
    i.	웹 서버 소프트 웨어 기능은 웹 브라우저로 부터 요청한 해석, 필요 웹 서버 응용프로그램 작동, 웹 서버 프로그램 실행 결과          를 웹브라우저에 전송 등이 있다.
      1.	웹 서버 소프트 웨어의 종류
          ex) Apache, nginx,GWS(Google Web Server)
  b.	웹 페이지의 주소, URL, URI, URN
    i.	URI은 인터넷 상의 리소스(자원)을 식별하기 위한 문자열의 구성이다. 
   ii.	URL은 URI의 하위 개념으로 정형화된 리소스 위치 또는 통합 자원으로 위치이다. (URL은 자원의 위치를 나타낸다.)
  iii.	URN은 URI의 하위 개념으로 정형화 된 리소스 이름 또는 통합 자원 이름이다.(URN은 변하지 않는 이름이다.)
4.	웹 페이지 구성
  a.	웹 페이지 구성 3요소
    i.	웹 페이지의 구조와 내용 - HTML***
   ii.	웹 페이지의 모양 - CSS
  iii.	웹 페이지의 행동 및 응용 프로그램 - Javascript
